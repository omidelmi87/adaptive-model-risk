# Data

This directory documents the public and reproducible data sources evaluated or used in the Adaptive Model Risk project.

Large raw datasets are not intended to be stored directly in this repository. Instead, this project will document:

- original data sources;
- data-access instructions;
- relevant licenses or usage restrictions;
- preprocessing procedures;
- modeling periods;
- derived variables;
- reproducibility steps.

## Planned Data Structure

As the project develops, the local data environment may use the following structure:

```text
data/
├── raw/
├── external/
├── interim/
└── processed/
```

These directories may be excluded from version control where appropriate.

## Current Status

Dataset evaluation has not yet been finalized.

The project will initially focus on publicly available or appropriately licensed financial, credit-performance, and macroeconomic datasets that allow analysis across different economic environments and time periods.
